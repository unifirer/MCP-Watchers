## TRAP — this repo's test runner cannot report failure (found, fixed, still dangerous)

1. `powershell -File suite.tests.ps1` returns 0 no matter how many Pester tests fail.
2. Every suite's trailing summary prints `Passed: 0 Failed: 0` (the nested
   `Invoke-Pester` rediscovers zero tests). Grepping it says "green" for a red suite.
   → **Always count `[+]` / `[-]` markers** in `temp/_gate.out.txt`. Each suite runs
   twice, so counts are 2x the test count.

Because of this, `mcpw-ybs.2b`'s suite (`launcher_sweep_attribution.tests.ps1`) was
**born red and reported green**: the extracted sweep block ended after
`Stop-PriorLauncherInstances`' column-0 `}` (one brace too many → `Invoke-Expression`
threw), and one test dot-sourced the module inside the `{ }` given to `Should`.
Fixed in `bb48c91`.
