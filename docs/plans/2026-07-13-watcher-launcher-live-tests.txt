# Watcher-Launcher Live-Data Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add tests that exercise the *live data* produced and consumed by the `###1` watcher launcher — its persisted `teardown-state.json` (RootPids / MemtraceStatePath / RepoRoot) and the launch → detect → teardown loop for a real watcher — without modifying the protected `###1` script.

**Architecture:** Three new test files in `tests/` (the `###1` launcher is protected and must NOT be edited). One static contract-lock file pins the exact tokens the launcher emits; one LIVE round-trip test proves `Stop-AllWatchers` (the launcher's `PowerShell.Exiting` handler) recovers real PIDs from the persisted state file and kills them; one LIVE test proves a real `grepai watch --background` watcher is detected as live and then torn down by the same shared teardown module. Tests reuse the repo's process-isolated runner (`run_tests_isolated.py`) and the existing `filelock` global-lock pattern so parallel light workers never fight over the single global grepai watcher or the single global `teardown-state.json`.

**Tech Stack:** Python + pytest + `filelock`, PowerShell (`pwsh.exe`/`powershell.exe`) driven via `subprocess`, CIM (`Get-CimInstance Win32_Process`) for live-process detection, `grepai`/`memtrace`/`gm`/`repowise`/`graphify-rs` CLIs (all confirmed present on PATH in this environment).

## Context the engineer needs

- **The launcher is protected.** Its filename starts with `###`, so `AGENTS.md` forbids moving or modifying it. ALL work here is *new test files*. Do not edit `###1. watchers for memtrace grepai graphenium graphify-rs repowise.ps1`.
- **The launcher writes live data** to `$env:LOCALAPPDATA\watchers\teardown-state.json` with this exact shape:
  ```json
  { "RootPids": [<int>], "MemtraceStatePath": "<repo>/.memdb/daemon-state.json", "RepoRoot": "<script dir>" }
  ```
  `RepoRoot` is `$scriptDir = $PSScriptRoot` (the repo root, since the launcher lives directly in repo root).
- **The teardown module** `modules/watcher_teardown.ps1` (already in the repo) exposes `Stop-AllWatchers`, `Stop-WatcherTree`, `Find-WatcherProcesses`, `Invoke-TeardownStep`, `Write-TdState`. `Stop-AllWatchers`, when called with NO arguments, reads `teardown-state.json` from `$env:LOCALAPPDATA\watchers\` (the launcher's `PowerShell.Exiting` path runs in a separate runspace and has no script scope, so it MUST read the file). It then tree-kills every RootPid, runs a CIM sweep matching `CommandLine -match 'watch'` for `grepai.exe`/`repowise`/`gm`/`graphify`/powershell pane scripts, and finally calls `grepai watch --stop`.
- **Existing related tests (do NOT duplicate):** `tests/test_launcher_gm_wiring.py` (gm wiring only), `tests/test_launch_watcher_teardown.py` (launcher's teardown *wiring* only — static), `tests/launcher_watcher_teardown.tests.ps1` (Pester suite for `Stop-WatcherTree`), `tests/test_launch_watcher.py` + `tests/test_launch_watcher_standalone.py` (grepai launcher `###3`, including the proven `serving` readiness pattern and the `tests/.grepai_watcher_tests.lock` global grepai lock).
- **Runner:** `run_tests_isolated.py` runs pytest per-file in its own process, classifies each as LIGHT/HEAVY, and runs LIGHT in parallel. Our three files contain no heavy markers (no torch/silero/vad_model_loader), so they are LIGHT and may run concurrently — hence the explicit global locks below.
- **Live-process safety (AGENTS.md §4.3):** no test may leave a visible window. All processes are spawned hidden (`creationflags=0x08000000` / `-WindowStyle Hidden`), and every test kills what it spawns before returning (via the teardown module, `taskkill /t`, or `grepai watch --stop`).

## File structure

- Create: `tests/test_launcher_watchers_contract.py` — STATIC contract locks (fast, no processes). Asserts the launcher emits all five watcher tokens, the persisted-state shape, the `RepoRoot` derivation, the helper functions, and that the file parses cleanly in PowerShell.
- Create: `tests/test_launcher_teardown_state_live.py` — LIVE round-trip of `teardown-state.json`. Spawns a real hidden tracked process, writes the exact state shape, calls `Stop-AllWatchers` with no args, asserts the process died because the module recovered its PID from the file.
- Create: `tests/test_launcher_watcher_live_tracking.py` — LIVE launch+detect+teardown of a real `grepai watch --background` watcher, using the launcher's shared teardown module and the proven `serving` readiness pattern.
- Reuse (read-only): `modules/watcher_teardown.ps1`, `run_tests_isolated.py`.
- New lock files (auto-created by `filelock`): `tests/.launcher_teardown_state.lock` — serializes every read/write of the GLOBAL `teardown-state.json` across the two live tests so the crafted ping-state from one test is never present when the other's `Stop-AllWatchers` reads the file. (The grepai lock `tests/.grepai_watcher_tests.lock` is reused FROM the existing grepai tests.)

These tests pin the exact tokens the launcher emits so a refactor that drops a

spawned. Behavioral teardown is covered by the Pester suite plus the live tests

### Task 2: LIVE round-trip of the persisted teardown-state.json

**Files:**
- Create: `tests/test_launcher_teardown_state_live.py`

- [ ] **Step 1: Write the live state round-trip test**

Create `tests/test_launcher_teardown_state_live.py`:

```python
"""LIVE round-trip test of the launcher's persisted live-state data.

The ###1 launcher writes $env:LOCALAPPDATA/watchers/teardown-state.json with
{ RootPids, MemtraceStatePath, RepoRoot }. Its PowerShell.Exiting handler (a
separate runspace with no script scope) calls Stop-AllWatchers with NO args,
which MUST read that file to recover the tracked PIDs. This test proves the
round-trip on REAL data: we write the exact state shape, spawn a real tracked
process, call Stop-AllWatchers with no args, and assert the process died because
the module recovered its PID from the file.

Safety: we never clobber an active launcher session, and we restore/remove the
state file in a finally block. The global teardown-state.json is serialized via
tests/.launcher_teardown_state.lock so this test never overlaps with
test_launcher_watcher_live_tracking.py's Stop-AllWatchers read.
"""
import json
import os
import subprocess
import time
from pathlib import Path

import pytest
from filelock import FileLock

ROOT = Path(__file__).parent.parent
MODULE = ROOT / "modules" / "watcher_teardown.ps1"
STATE_DIR = Path(os.environ["LOCALAPPDATA"]) / "watchers"
STATE_FILE = STATE_DIR / "teardown-state.json"
_STATE_LOCK = FileLock(str(ROOT / "tests" / ".launcher_teardown_state.lock"), timeout=300)


def _spawn_tracked_child():
    # Isolated, long-lived, hidden: ping has no children, so the module's tree-kill
    # targets exactly this PID (no risk of killing unrelated work).
    return subprocess.Popen(
        ["ping", "-n", "120", "127.0.0.1"],
        stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
        creationflags=0x08000000,  # CREATE_NO_WINDOW
    )


def _pid_alive(pid):
    res = subprocess.run(
        ["pwsh.exe", "-NoProfile", "-Command",
         f"if(Get-Process -Id {int(pid)} -ErrorAction SilentlyContinue){{exit 0}}else{{exit 1}}"],
        capture_output=True,
    )
    return res.returncode == 0


def _launcher_session_active():
    """Skip if a real ###1 launcher session is live, so we never disturb the user's
    running watchers or clobber a genuine state file."""
    if not STATE_FILE.exists():
        return False
    try:
        data = json.loads(STATE_FILE.read_text(encoding="utf-8"))
    except Exception:
        return False
    if Path(data.get("RepoRoot", "")).resolve() != ROOT.resolve():
        return False
    return any(_pid_alive(int(p)) for p in data.get("RootPids", []))


@pytest.fixture
def guarded_state_file():
    snapshot = STATE_FILE.read_text(encoding="utf-8") if STATE_FILE.exists() else None
    STATE_DIR.mkdir(parents=True, exist_ok=True)
    try:
        yield
    finally:
        if snapshot is None:
            STATE_FILE.unlink(missing_ok=True)
        else:
            STATE_FILE.write_text(snapshot, encoding="utf-8")


def test_stop_all_watchers_reads_live_state():
    if MODULE.exists() is False:
        pytest.skip("watcher_teardown.ps1 module missing.")
    if _launcher_session_active():
        pytest.skip("A real ###1 launcher session is active; not disturbing it.")

    with _STATE_LOCK:
        child = _spawn_tracked_child()
        try:
            # Write the EXACT shape the launcher produces, with our real PID.
            state = {
                "RootPids": [child.pid],
                "MemtraceStatePath": str(ROOT / ".memdb" / "daemon-state.json"),
                "RepoRoot": str(ROOT),
            }
            STATE_FILE.write_text(json.dumps(state), encoding="utf-8")

            time.sleep(0.5)
            assert _pid_alive(child.pid), "precondition: tracked child must be alive"

            # The exact call the PowerShell.Exiting handler makes (no args -> reads the file).
            res = subprocess.run(
                ["pwsh.exe", "-NoProfile", "-Command",
                 f'. "{MODULE}"; Stop-AllWatchers'],
                capture_output=True, text=True,
            )
            assert res.returncode == 0, f"Stop-AllWatchers failed: {res.stderr}"

            dead = False
            for _ in range(40):
                if not _pid_alive(child.pid):
                    dead = True
                    break
                time.sleep(0.25)
            assert dead, ("Stop-AllWatchers did NOT recover the PID from teardown-state.json "
                          "and tree-kill it.")
        finally:
            if _pid_alive(child.pid):
                subprocess.run(["taskkill", "/pid", str(child.pid), "/f", "/t"],
                               capture_output=True, check=False)
```

### Task 3: LIVE launch → detect → teardown of a real watcher

Create `tests/test_launcher_watcher_live_tracking.py`:

```python
"""LIVE test of the launcher's watcher launch + live-detection + teardown loop.

The ###1 launcher launches `grepai watch --background` as a tracked watcher and
records its root PID in teardown-state.json. Stop-AllWatchers tears it down via a
CIM pattern sweep (CommandLine -match 'watch') + `grepai watch --stop`. This test
proves that loop end-to-end on a REAL grepai watcher: launch it, verify it is live
(launcher-equivalent detection), then drive the launcher's shared teardown module
and verify it is gone.

Serialization:
  - tests/.grepai_watcher_tests.lock  (REUSED from the existing grepai tests) guards
    the single global grepai background watcher so parallel light workers never fight.
  - tests/.launcher_teardown_state.lock guards the single global teardown-state.json
    so this test's Stop-AllWatchers read never overlaps the crafted ping-state in
    test_launcher_teardown_state_live.py.
"""
import json
import os
import shutil
import subprocess
import time
from pathlib import Path

import pytest
from filelock import FileLock

ROOT = Path(__file__).parent.parent
MODULE = ROOT / "modules" / "watcher_teardown.ps1"
STATE_DIR = Path(os.environ["LOCALAPPDATA"]) / "watchers"
STATE_FILE = STATE_DIR / "teardown-state.json"
_GREPAI_LOCK = FileLock(str(ROOT / "tests" / ".grepai_watcher_tests.lock"), timeout=300)
_STATE_LOCK = FileLock(str(ROOT / "tests" / ".launcher_teardown_state.lock"), timeout=300)


def _grepai_watcher_serving():
    logs_dir = Path.home() / "AppData" / "Local" / "grepai" / "logs"
    ready = list(logs_dir.glob("grepai-worktree-*.ready"))
    cim = subprocess.run(
        ["powershell.exe", "-NoProfile", "-Command",
         "Get-CimInstance Win32_Process -Filter \"Name='grepai.exe'\" | "
         "Where-Object { $_.CommandLine -and $_.CommandLine -match 'watch' } | "
         "Measure-Object | Select-Object -ExpandProperty Count"],
        capture_output=True, text=True,
    ).stdout.strip() not in ("", "0")
    return bool(ready) and cim


def _pid_alive(pid):
    res = subprocess.run(
        ["pwsh.exe", "-NoProfile", "-Command",
         f"if(Get-Process -Id {int(pid)} -ErrorAction SilentlyContinue){{exit 0}}else{{exit 1}}"],
        capture_output=True,
    )
    return res.returncode == 0


def _launcher_session_active():
    """Skip if a real ###1 launcher session is live, so we never tear down the
    user's running watchers or clobber a genuine state file."""
    if not STATE_FILE.exists():
        return False
    try:
        data = json.loads(STATE_FILE.read_text(encoding="utf-8"))
    except Exception:
        return False
    if Path(data.get("RepoRoot", "")).resolve() != ROOT.resolve():
        return False
    return any(_pid_alive(int(p)) for p in data.get("RootPids", []))


def test_live_grepai_watcher_tracked_and_torn_down():
    if shutil.which("grepai") is None:
        pytest.skip("grepai CLI not available")
    if MODULE.exists() is False:
        pytest.skip("watcher_teardown.ps1 module missing")
    if _launcher_session_active():
        pytest.skip("A real ###1 launcher session is active; not disturbing it.")

    with _GREPAI_LOCK:
        # Bring a real grepai background watcher to serving (the launcher's mode).
        subprocess.run(["grepai", "watch", "--stop"], check=False)
        time.sleep(2)
        subprocess.run(["grepai", "watch", "--background"], check=False)

        serving = False
        for _ in range(30):
            time.sleep(1)
            if _grepai_watcher_serving():
                serving = True
                break
        if not serving:
            pytest.skip("grepai watcher did not reach a serving state in this environment")

        # LIVE DETECTION: the watcher is actually running (launcher-equivalent).
        assert _grepai_watcher_serving(), "precondition: grepai watcher must be live"

        # TEARDOWN via the launcher's shared module (no-arg form runs the CIM sweep
        # + `grepai watch --stop`). Guard the global state file during the read.
        with _STATE_LOCK:
            res = subprocess.run(
                ["pwsh.exe", "-NoProfile", "-Command",
                 f'. "{MODULE}"; Stop-AllWatchers'],
                capture_output=True, text=True,
            )
            assert res.returncode == 0, f"Stop-AllWatchers failed: {res.stderr}"

        gone = False
        for _ in range(40):
            time.sleep(0.5)
            if not _grepai_watcher_serving():
                gone = True
                break
        assert gone, "Stop-AllWatchers did not tear down the live grepai watcher."
```
